# Pie Chart Scanner & Alert System

Minecraft Fabric client mod for Minecraft 1.21.11.

The project is built automatically with GitHub Actions. Open the Actions tab, select the latest successful `build` run, and download the `Artifacts` artifact. The runnable mod JAR is in `build/libs/` (do not use the `-sources.jar`).

Requires Fabric Loader, Fabric API, and Java 21 or newer (the workflow uses the JDK version configured in the project).
